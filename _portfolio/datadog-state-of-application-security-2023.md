I wrote Datadog's first State of Application Security report, built on runtime data from thousands of organizations. Its findings include that only 3% of critical vulnerabilities are worth prioritizing once you have runtime context, that 74% of attacks are unlikely to succeed, that Java services carry the highest risk, and that SQL injection and SSRF are still everywhere.
